# superstore-bi-dashboard
# Анализ продаж интернет-магазина (Superstore E-commerce)

Интерактивный дашборд для отслеживания продаж и прибыли e-commerce магазина.

## 🔗 Ссылки на проект
* **Интерактивный дашборд:** https://public.tableau.com/views/Superstoresalesperformancedashboard_17931823721880/Dashboard1?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

* **SQL-код для базы данных:** [init_db.sql](init_db.sql)

## 🎯 Что делает этот проект 
* Автоматизирует отчеты по продажам, чтобы менеджеры не считали их вручную
* Показывает, в какие месяцы продажи растут сильнее всего (сезонность)
* Помогает найти самые выгодные и самые убыточные категории товаров

## 🛠️ Инструменты
* **SQL (PostgreSQL):** Создание таблиц и расчет выручки
* **Tableau:** Построение интерактивных графиков и настройка фильтров

## 📊 Главные выводы из графиков
1. **Пик продаж:** Каждый год продажи резко растут в конце года — в ноябре и декабре. К этому нужно заранее готовить склад.
2. **Проблема с мебелью:** Категория "Технологии" приносит больше всего чистой прибыли. А вот "Мебель" почти не приносит денег. Компании нужно либо поднимать цены на мебель, либо закупать её дешевле.
